# HAMU MASTER — Admin Fly Editing V6

Admin-only live gameplay editor.

- FLY EDITING button + F9 toggle
- spectator/free camera: WASD/QE, Shift fast, RMB look
- click any visible 3D object to select it
- drag selected object in the world
- transform inspector (position/rotation/scale)
- rename, hide/delete, duplicate
- PNG/JPG/WebP drag/drop image assets as 3D sprites
- Ctrl+Z / Ctrl+Shift+Z / Ctrl+Y undo/redo
- SAVE + LIVE SYNC persists to the protected server config and broadcasts to connected clients
- only authenticated admin sessions can write editor changes

Server port for this upgrade: 3000.
