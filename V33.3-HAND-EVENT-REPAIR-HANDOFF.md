## Startup and data safety

Node.js 20+. Extract to a **new directory**, enter `hamu-master`, run `npm ci`. For normal owner use, `npm start` starts the unchanged normal server; read its printed port (do not assume 3000 if PORT is configured). Do not use `start.bat` for validation or bundled admin credentials.

Set HAMU_DATA_DIR to a fresh temporary directory for each isolated test. For account-free server smoke tests use the exported `createGameServer({dataDir: process.env.HAMU_DATA_DIR, migrateLegacy:false})` and `start({port:0,host:'127.0.0.1'})`; the evidence script does this. The normal server can migrate project `data/` if present, so a fresh data directory alone is not a universal migration-disable switch. Never point testing at real saves; back them up before any owner migration.

**Keep the full game ZIP private. Original private/account-related material and launcher credential content are deliberately retained unchanged, not approved for publication. A separate release/privacy/security pass is required.** Dependencies, temporary accounts, caches and browser profiles are not bundled. No original game files were deleted.
