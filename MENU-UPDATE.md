# Quick Play Menu Update — 14 September 2026

The Quick Play lobby has been redesigned around the supplied cinematic reference direction while retaining the existing 3D character stage and all existing navigation/actions.

- Left tactical navigation rail for Play, Loadout, Weapons, Characters, Friends, Match History and Settings.
- Center stage remains the actual selected imported character rendered by the existing WebGL renderer; no replacement artwork/model is used.
- Left deployment deck contains the existing authoritative modes and matchmaking action.
- Right profile/social rail uses the authenticated account's own username, level and XP. It does not hard-code a sample username.
- Bottom character and weapon strips retain the existing operator/loadout selection actions.
- Existing account/auth/profile/persistence/server files and supplied account data were not modified.
- Responsive fallback remains for narrower screens.

The generated reference image was used only as visual direction; the game uses its own existing assets and 3D scene.
